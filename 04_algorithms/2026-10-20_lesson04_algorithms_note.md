# 第04节课学习笔记：Algorithms（核心原理 + 模型架构）

## 学习目标
- 理清常见算法范式与适用场景。
- 从“问题建模—状态设计—复杂度分析”角度组织复习。
- 将容易混淆的问题直接记录在对应知识点下。

## 1. 问题建模方法
- 第一步：明确输入、输出、约束。
- 第二步：判断问题类型（搜索、最优、计数、预测）。
- 第三步：确定评估指标（正确性、时间、空间、鲁棒性）。

**常见问题**
- 问题：题目看懂了却不知道选什么算法？  
  - 先看“状态是否可分解”和“是否有重叠子问题”。
- 问题：实现出来但复杂度超标？  
  - 先写复杂度上界，再反推是否需要剪枝或降维。

## 2. 图搜索与路径规划基础
### 2.1 BFS / DFS
- BFS：适合无权图最短步数。
- DFS：适合连通性、拓扑结构探索。

### 2.2 Dijkstra / A*
- Dijkstra：非负权图最短路，核心是贪心扩展最小代价点。
- A*：在 Dijkstra 上加入启发函数 `f(n)=g(n)+h(n)`。

**常见问题**
- 问题：A* 为什么有时不最优？  
  - 启发函数不满足可采纳性（高估真实代价）。
- 问题：路径抖动严重？  
  - 网格分辨率或代价函数设计不合理，需要平滑策略。

## 3. 动态规划（DP）
### 3.1 DP 架构模板
1. 定义状态：`dp[i][j]` 表示什么。  
2. 设计转移：从哪些子状态转移而来。  
3. 边界初始化。  
4. 遍历顺序与答案读取。

**常见问题**
- 问题：状态定义总是混乱？  
  - 先用自然语言写“状态语义”，再写数组。
- 问题：转移方程对但结果错？  
  - 多数是初始化或遍历方向错误。

## 4. 机器学习基础模型架构（复习导向）
- 线性模型：输入特征加权求和，解释性强。
- MLP：多层非线性映射，表达能力更强。
- CNN：局部感受野 + 参数共享，适合图像。
- Transformer：自注意力建模全局依赖，适合序列。

**常见问题**
- 问题：训练集效果好，测试集效果差？  
  - 典型过拟合，可从正则化、数据增强、早停入手。
- 问题：模型很深但收益有限？  
  - 可能是特征质量和数据规模成了瓶颈。

## 附录：语法/公式速查（放在文档末尾）
### A. 复杂度常见写法
- 线性：`O(n)`
- 对数：`O(log n)`
- 二维 DP：`O(n*m)`

### B. A* 评估函数
- `f(n) = g(n) + h(n)`
  - `g(n)`: 起点到当前点真实代价
  - `h(n)`: 当前点到终点启发估计

### C. DP 伪模板（语义）
- 状态定义
- 状态转移
- 初始条件
- 遍历顺序
